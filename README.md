# STREAM 2026 – Scientist Games Arena
Classroom to Cosmos · Category 2 (AI, Gamification & Cybersecurity) · Class XI, Govt. Boys HSS Bhansinghabad, Mirpurkhas.

Static site: one `index.html`, no build step, no API keys, no database. Progress is saved in the browser's localStorage.

## Run locally
Open `index.html` in a browser, or run `npx serve .`

## Deploy on Vercel (free Hobby plan)
1. Push this folder to a GitHub repository.
2. On vercel.com choose **Add New → Project** and import the repo.
3. Framework Preset: **Other**. Leave Build Command and Output Directory empty.
4. Click **Deploy**. (Or run `npx vercel --prod` inside this folder.)

## Contents
Games: Cosmic Mission, AI Scientist, Cyber Defender, Physics Lab (+ projectile and F=ma simulators), Molecular Quest, Bio Quest.
Pages: Home, Games Arena, AI Lab, Cyber Center, Physics Lab, Dashboard, Leaderboard, Achievements, About.
All AI features are simulated, rule-based JavaScript, not generative AI.
